Finding 1: "resolved" Field Incorrect

The Problem

GET /metrics/batches/{id} reported resolved: 8 when the batch had 0 matched records and 8 exceptions. The resolved field was mapped from success_count, which is set to total records processed, not resolved exceptions.

Root Cause

batch_service.py run_batch() sets batch["success_count"] = total (all records processed), then get_summary() maps this to "resolved": batch.get("success_count", 0). Semantically, success_count means "processed without error", not "exceptions resolved".

Before Fix

{ "total_exceptions": 8, "resolved": 8, // ← WRONG: should be 0 "unresolved": 0, // ← WRONG: should be 8 "matched_records": 0 }

After Fix

{ "total_exceptions": 10, "resolved": 0, // ← matches matched_records "unresolved": 10, // ← equals total_exceptions "matched_records": 0 }

Code Change

"resolved": batch.get("success_count", 0), "unresolved": batch.get("failure_count", 0), "resolved": batch.get("matched_records", 0) or 0, "unresolved": batch.get("exception_count", 0) or 0,

Finding 2: Overall /metrics "unresolved" Was Always Zero

The Problem

GET /metrics reported unresolved: 0 even when exceptions existed. The get_metrics() method initialized unresolved = 0 but never populated it from batch data.

Root Cause

dependencies.py MetricsService.get_metrics() reads exception_count into exceptions but never computes unresolved from it. Since auto_resolved = 0 and human_review = 0 at batch level, unresolved should equal exceptions.

Code Change

# Before: uninitialized variable unresolved = 0 # Never updated! # After: computed from exception data unresolved = exceptions - auto_resolved - human_review

Finding 3: Safety guardrail_pass_rate Misleading at Zero

The Problem

GET /metrics/safety returned guardrail_pass_rate: 1.0 when zero decisions had been made. A 100% pass rate with zero decisions is semantically wrong.

Root Cause

dependencies.py MetricsService.get_safety_metrics() defaulted to 1.0 when total_decisions == 0. Mathematically, zero decisions has no meaningful pass rate.

Code Change

guardrail_pass_rate = (total_auto / total_decisions) if total_decisions > 0 else 1.0 guardrail_pass_rate = (total_auto / total_decisions) if total_decisions > 0 else None # Also updated the return dict: "guardrail_pass_rate": round(guardrail_pass_rate, 4), "guardrail_pass_rate": round(guardrail_pass_rate, 4) if guardrail_pass_rate is not None else None,

Result

{ "auto_decisions": 0, "guardrail_pass_rate": null // ← was 1.0 }
